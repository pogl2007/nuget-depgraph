# Граф зависимостей NuGet

Практическая работа №2, вариант 12. Этап 1.

CLI-инструмент для анализа зависимостей пакетов .NET (NuGet). Готовые
менеджеры пакетов и библиотеки для получения зависимостей не
используются.

## Параметры

- `--package NAME` — имя анализируемого пакета (обязательный)
- `--repo URL_OR_PATH` — URL репозитория или путь к файлу тестового
  репозитория (обязательный)
- `--test-mode` — работать с тестовым репозиторием (файлом)
- `--version VERSION` — версия пакета (обязательный)
- `--max-depth N` — максимальная глубина анализа, по умолчанию 3

При запуске все параметры выводятся в формате `ключ=значение`.

## Проверка параметров

- имя пакета: не пустое, не длиннее 100 символов, только латиница,
  цифры, `.`, `-`, `_`
- репозиторий: в обычном режиме URL с `http://` или `https://`,
  в тестовом режиме файл должен существовать
- версия: вида `1.0`, `3.1.1`, `8.0.0-preview.1`
- глубина: целое число не меньше 1

Если ошибок несколько, выводятся все сразу, код выхода 1. Нет
обязательного параметра или глубина не число — ошибку выдаёт
argparse, код выхода 2.

## Запуск

В PowerShell нужно писать `.\run.bat`, в cmd просто `run.bat`.

```
.\run.bat --package Serilog --repo https://api.nuget.org/v3-flatcontainer/ --version 3.1.1
```

Тестовый режим:

```
.\run.bat --package A --repo test_repos\simple.txt --test-mode --version 1.0
```

Все варианты параметров и ошибок:

```
.\os_scripts\test_config.bat
```

## Тесты

```
python -m pytest
```

## Пример

```
package=Serilog
repo=https://api.nuget.org/v3-flatcontainer/
test_mode=False
version=3.1.1
max_depth=5
```

```
package=Serilog
repo=ftp://example.com
test_mode=False
version=abc
max_depth=0
Ошибка: URL репозитория должен начинаться с http:// или https://: ftp://example.com
Ошибка: неверный формат версии: abc
Ошибка: глубина должна быть не меньше 1: 0
```
