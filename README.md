# Граф зависимостей NuGet

Практическая работа №2, вариант 12. Этапы 1-2.

CLI-инструмент для анализа зависимостей пакетов .NET (NuGet). Готовые
менеджеры пакетов и библиотеки для получения зависимостей не
используются: файл пакета скачивается через стандартный `urllib`,
а разбирается стандартным `xml.etree`.

## Параметры

- `--package NAME` — имя анализируемого пакета (обязательный)
- `--repo URL_OR_PATH` — URL репозитория или путь к файлу тестового
  репозитория (обязательный)
- `--test-mode` — работать с тестовым репозиторием (файлом)
- `--version VERSION` — версия пакета (обязательный)
- `--max-depth N` — максимальная глубина анализа, по умолчанию 3

Проверка параметров:

- имя пакета: не пустое, не длиннее 100 символов, только латиница,
  цифры, `.`, `-`, `_`
- репозиторий: в обычном режиме URL с `http://` или `https://`,
  в тестовом режиме файл должен существовать
- версия: вида `1.0`, `3.1.1`, `8.0.0-preview.1`
- глубина: целое число не меньше 1

Если ошибок несколько, выводятся все сразу, код выхода 1. Нет
обязательного параметра или глубина не число — ошибку выдаёт
argparse, код выхода 2.

На первом этапе параметры выводились в формате `ключ=значение`,
по заданию это нужно было только для первого этапа.

## Получение зависимостей

Используется API репозитория NuGet (flat container). Для пакета и
версии скачивается файл описания:

```
{repo}/{пакет}/{версия}/{пакет}.nuspec
```

например
`https://api.nuget.org/v3-flatcontainer/serilog/3.1.1/serilog.nuspec`.
Это XML, в нём зависимости лежат в `<dependencies>`, обычно по группам
для разных платформ (`net462`, `netstandard2.0` и т. д.). Программа
собирает зависимости из всех групп, убирает повторы и выводит список.

Версия рядом с зависимостью — как в `.nuspec`: `7.0.2` значит
«7.0.2 или новее», `[1.0, 2.0)` — диапазон.

Ошибки: пакет или версия не найдены (404), репозиторий недоступен,
неверный формат `.nuspec`. Тестовый режим будет на этапе 3.

## Запуск

В PowerShell нужно писать `.\run.bat`, в cmd просто `run.bat`.

```
.\run.bat --package Serilog --repo https://api.nuget.org/v3-flatcontainer/ --version 3.1.1
```

Все варианты параметров и их ошибки:

```
.\os_scripts\test_config.bat
```

Зависимости нескольких пакетов и ошибки репозитория:

```
.\os_scripts\test_deps.bat
```

Для этапа 2 нужен интернет.

## Тесты

```
python -m pytest
```

Тесты не ходят в сеть: ответ репозитория подменяется.
